The project aims to distinguish between the real and fake images and is trained on 10k images dataset which is complete made using StyleGAN2/StyleGAN technique. Now the file structure is as follows:-

1. The Training Notebook : ee604-resnet50.ipynb
2. The results from training the model without the use of handcrafted features : ee604-final.ipynb
3. The final notebook containing all the results and the final synthetic feature generation and then concatenating all the features into a deep neural network : final-classifier-notebook.ipynb
